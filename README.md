## The joke

> My performance review said I need to be more visible, so now I reply-all to everything.

## How it works

`main.py` (Python 3.13, standard library only) writes that single line —
under 200 characters, and nothing else — deterministically to
`/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
